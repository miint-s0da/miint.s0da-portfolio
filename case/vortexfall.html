01 // CHALLENGE

AI로 만든 조각들을 하나의 세계로

게임 팬은 출시 전 세계관과 캐릭터에서 먼저 생긴다. 그래서 정보를 나열하는 홍보 페이지가 아니라, 스크롤하는 동안 그 세계 안에 들어가 있는 런칭 사이트를 목표로 했다. 가장 큰 과제는 생성할 때마다 얼굴·색·분위기가 달라지는 AI 결과물을 하나의 세계로 묶는 것이었다.

GOAL스크롤하는 동안 두 세계 안에 들어가 있는 느낌을 주는 게임 IP 런칭 쇼케이스

02
UX RATIONALE

왜 원페이지 스크롤인가

HOOK인트로 · 히어로→UNDERSTAND세계 · 에너지→ATTACH캐릭터→IMAGINE플레이 · 시스템→FEEL미디어→ACTION사전예약

런칭 사이트의 목적은 "세계관을 이해시키고 → 사전예약으로 이어지게" 하는 하나의 흐름이라, 섹션 순서를 이 흐름에 맞췄다.

UX 02

설명 대신 직접 조작

"같은 좌표, 다른 법칙"은 글로 읽으면 추상적이다.

두 세계는 드래그 비교, 에너지는 STABLE / UNSTABLE 전환으로 손으로 이해하게 했다.

UX 03

목표 행동을 항상 가까이

사전예약이 맨 끝에만 있으면 도중에 이탈한다.

상단에 PRE-REGISTER를 고정하고 히어로에도 사전예약 버튼을 바로 두었다.
