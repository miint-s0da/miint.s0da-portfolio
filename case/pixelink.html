CASE STUDY · 02

PIXELINK

PIXEL + NEON, LINKED. 픽셀 레트로와 사이버팝을 섞은 오리지널 캐릭터 IP 브랜드 사이트

유형오리지널 캐릭터 IP 브랜드 사이트 (인트로 + 메인 + 서브페이지)
역할기획·브랜드 방향·디자인 디렉션: miint.s0da · 개발: Claude Code
기술HTML / CSS / JavaScript 단일 파일, WebAudio, PWA, Vercel
상태재작업 중, 1차 오픈 전

01 · CHALLENGE왜 만들었나

과제 — 인트로부터 메인까지 한 번에 이어지고, 굿즈 소개가 우선이면서 캐릭터를 직접 만져 보는 경험을 갖는 사이트.

목표 — 캐릭터(CHI:EE · LEENKI · GLEEN)를 소개하고, 입어 보기 → 알게 되기 → 모으기 → 갖기(실물 굿즈)로 이어지는 흐름의 첫 단계를 만든다.

02 · UX사용자 흐름과 근거

흐름 — 인트로(카세트 삽입) → 메인 히어로 PRESS START → 캐릭터·아트워크·월드·굿즈 탐색 → 드레스룸에서 CHI:EE 입혀 보기

문제 방문할 때마다 인트로가 나오면 메인을 확인하는 데 방해가 된다.
해결 처음 방문에만 30일간 1회, SKIP 버튼·Esc, 메인의 INTRO 버튼으로 다시 보기.

문제 모든 카드가 같은 호버라 단조롭고, 떠오르며 빛나는 호버는 다른 사이트와 겹친다.
해결 섹션·캐릭터마다 다른 통통 반응과 효과음, 빛 효과 제거.
