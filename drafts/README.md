# 포트폴리오 개편 시안 모음

공개 사이트에는 올라가지 않는다 (`.vercelignore`에서 제외). 로컬에서 각 폴더의 `index.html`을 열어 비교한다.

## 정한 방향 (2026.11)
- 에디토리얼 레이아웃 + 휴먼 엣지(손맛·질감) — 2027 트렌드와 일치
- 작업물이 먼저 보이게: 프로젝트는 실제 사이트 화면으로
- 개성: 프로젝트별 색 별(✦) 시스템, 섹션별 로고 색 변화
- 캐릭터는 쓰더라도 작게 한 번 (본인 기반)
- 대표 3개(UNI+ON, PIXELINK, VORTEXFALL) + 구상 중 2개(MO:A, GYEOL)

## 시안
| 폴더 | 이름 | 메모 |
|---|---|---|
| `collage/` | Collage Editorial | 히어로 = 큰 워드마크 타이포 + 실제 사이트 화면을 찢은 종이 조각·테이프·색 종이·손글씨·손그림 별로 콜라주. 2027 S/S 컬러(Luminous Blue·Energy Orange·Pop Pink·Meadowland Green·Clay, 근사값)를 프로젝트 색으로 배정: UNI+ON 오렌지 · PIXELINK 핑크 · VORTEXFALL 블루 · GYEOL 그린 · MO:A 클레이. 프로젝트를 고르면 로고 색이 그 색으로 바뀜 |
| `notebook/` | Notebook (다꾸) | 소개 페이지 무드(줄노트·펀칭홀·여백선, 클립·바인더·스테이플·압정·테이프, 손글씨, 클릭 별 파티클)를 메인에 적용. 4색 팔레트, 히어로에 일러스트 3장(`img/`), 프로젝트는 크기·기울기·고정 방식이 다른 스크랩. MORE ABOUT 링크는 (추후) |
| `grid-collage/` | Grid Collage (2027) | Gemini 03번(2px 보더 그리드·망점·인덱스 번호)을 기본으로 01번 요소(테이프·틸트 폴라로이드·손그림 밑줄·마키)를 합침. 팔레트 4색만 사용: #EFECE4 · #111914 · #1D4ED8 · 라임 #D4FF00(기존 다크모드 라임, 애시드 라임 #D9F99D로 교체 가능). 마스트헤드 miint.s0da, 필터 없음, 벤토(UNI+ON 2칸) + 제작 중 2개. 카피는 사용자 제공 문구 |
| `field-notes/` | Creative Field Notes | 종이 그레인, 세리프 헤드라인 "Make it matter.", 왼쪽 프로젝트 인덱스 + 오른쪽 큰 대표 이미지, 그린 매니페스토 띠. 정리: 오타(VORTEXFALL), 이메일, 구상 중 표시, 실제 도구로 교체, 이미지 경로를 `build/`로 |
